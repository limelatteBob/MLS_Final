# 隐私、信任模型与恢复语义

## 保护对象

保护单位为一张训练图片记录；不保护整个农场的参与、标签分布或同一叶片全部相关图片。服务器诚实但好奇、客户端按协议运行，安全聚合基础分析不假定服务器与客户端串通。攻击者控制终端、模型投毒、流量分析不在实现保护范围内。

公开 PlantVillage 数据在本项目中模拟私有分区。单进程模拟器能够访问这些分区和客户端状态，因此不能把本机文件或进程边界称为真实安全隔离。网络模式、认证传输、密钥持久化和客户端沙箱仍属于生产部署工作。

## DP-SGD

改进配置先使用明确划出的公共池训练特征提取器，验证集只负责模型选择；公共池不得混入私有训练分区。之后冻结卷积特征，只对分类头执行同样的逐样本裁剪、Poisson 抽样和 Gaussian 噪声记账。只训练分类头不会自动降低 epsilon；实际预算仍由采样率、噪声倍率与步骤数计算。公共初始化按清单、公共行摘要、预处理配置校验，新运行还记录检查点 SHA256。此路线依赖公开且有代表性的标注数据，需要同时报告公共模型基线。

`evaluate_test=false` 禁止训练流程计算测试指标，并禁止自动导出时隐式评估测试。冻结配置后执行 `evaluate-run` 生成独立 `final_test.json`，同时报告公共模型的测试指标；若最佳轮次为 0，表示没有证据表明私有微调优于公共初始化。归一化操作包含在模型前向及 ONNX 图中，训练和部署使用相同预处理。

训练采用 Opacus `GradSampleModule`、`DPOptimizer`、`DPDataLoader`：Poisson 抽样、逐样本梯度裁剪和 Gaussian 噪声。客户端本地执行这一算法不等于严格 local-DP 模型。

逻辑采样率按实际 loader 的 batch 数计算，不能简单把标称 batch size 除以样本数。物理微批次仅分块计算同一逻辑批次的裁剪梯度，通过 `signal_skip_step` 累计，最后一次加噪并更新。Poisson 空批次也执行加噪更新，不能跳过后仍沿用原采样分析。

每个客户端以 RDP accountant 合成所有已预留的逻辑步骤，delta 默认 1e-5，epsilon 上限为 4 或 8。噪声按该客户端最大学习采样率和最多 rounds×local_steps 校准，不利用资源调度的额外抽样放大。账本保存在运行目录 `private/client_*.json`。

写入顺序：预测下一步 epsilon → 检查预算 → 原子持久保存隐私消耗 → 执行训练步骤。崩溃可能多计未完成步骤，但不会少计。恢复全局模型不会恢复账本；缺失、损坏或身份／预算不匹配的账本导致停止。账本没有针对恶意本机操作者的防回滚存储保证。

对相同噪声和采样率缓存单步 RDP 向量，再按步骤数线性组合；测试将混合采样率／噪声的结果与 Opacus 原始 accountant 比对，避免每一步重复计算相同积分。运行目录采用内核文件锁禁止两个写入进程竞争账本。异常恢复有明确次数上限，重试不会重新初始化已有账本。

伪随机种子支持复现。真正的私有部署需要安全噪声随机源，不能公开噪声种子。本研究报告中的 epsilon 是该随机机制的会计结果；不能将“固定且公开种子”的实验直接宣称为密码学强度的部署 DP。多次运行若使用同一真实私有数据，需要跨运行组合预算；本实现只实现每次运行内部跨轮次的组合。

## 安全聚合

实际调用 Flower `SecAggPlusWorkflow` 和客户端 `secaggplus_mod`，模拟传输使用 Flower Protobuf 序列化，服务器策略只接收恢复后的聚合。返回权重固定为 1，从而实现 farm 等权平均。编码默认限制参数范围 [-8,8]，使用 Flower 的固定点随机量化；数值测试允许有限编码误差。

六客户端配置使用六份 share 与四份重建阈值。更新收集阶段的掉线在客户端训练后注入，已发生的 DP 消耗保留；至少四名上传者时可恢复，三名上传者时中止。unmask 阶段掉线不删除已经收到的掩码更新。setup/share-keys 阶段的掉线触发提前中止，避免已固定版本的上游协议请求不存在的份额。新一轮重新生成协议临时状态。

研究者可在测试中使用人工构造的明文向量验证聚合精度；受保护训练没有以明文聚合作为失败回退。单机消息传输没有 TLS，本地代码隔离不等于部署时服务器无法查看客户端内存。

## 发布与指标边界

监控写入函数只接受明确允许的字段，拒绝私有损失、图片、梯度和个体更新。模型选择只用独立验证集；量化与蒸馏只用公共池。测试集用于固定流程完成后的报告，不选择超参数。

客户端身份、参与情况、模拟设备信息、隐私参数与账本摘要被视为允许发布的运行信息。采样率与步骤等参数可能间接透露分区规模信息，因此不能同时宣称隐藏全部规模元数据。数据分区文件、私有账本和检查点是本地实验产物，不应未经审查发布为真实私有部署的监控内容。
