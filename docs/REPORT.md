# FedCrop 实现与预实验报告

> 后续更新：本页保留最初短预算实验的历史结果。2026-11-10 已修正测试侧保留策略、增加公共预训练与隐私分类头训练，并完成三个新版联邦种子及无隐私对照。新版测试 macro-F1 为 0.7161 ± 0.0004，但未超过公共模型基线；12 个客户端均参与。最新数据、33 项测试、压缩结果和剩余局限请以 [改进记录](IMPROVEMENTS.md) 和 [实测结果](IMPROVEMENT_RESULTS.md) 为准。下文的 2,834 张子集与摄像头不可行结论对应旧配置。

整理日期：2026-11-10；实验于 2026-11-09 执行。本文记录已运行的实现与预实验，并为课程最终报告提供依据；不声称已经完成全量数据、全部压力测试或高质量实际部署。最终排版可据此扩展为提案要求的 8—10 页报告。

## 1. 问题与研究贡献

目标是在非 IID 农场数据、异构资源和明确隐私预算下完成番茄十类图像分类。系统贡献是将真实隐私训练、安全聚合、参与公平性、设备预算、模型压缩和可审计恢复整合为可重复的实验平台。FedAvg、DP-SGD、SecAgg+ 和量化均来自已有方法，不声称提出新的密码协议或联邦学习算法。

主要研究问题是：在相同隐私条件下，资源调度能否改善质量达标时间；失败恢复能否保持预算一致；推理压缩是否改善真实 CPU 成本。以下证据分别支持实现正确性、预实验现象与尚未解决的质量问题。

## 2. 数据与泄漏审计

数据采用固定版本 PlantVillage 彩色番茄图像。当前开发子集共 2834 张，训练／验证／公共池／测试数量分别为 1203／155／149／1327。官方映射可验证的图片为 2339 张，跨原始划分的重复组件共隔离 152 张。

原始 proposal 对叶片分组的假设不完整：官方映射缺少花叶病毒类别，其他类别也存在无法匹配的文件。十类模式将这些图片标记为未验证，按规范化文件名与图像重复关系构建代理组。Target Spot 的文件名前缀别名修复揭示了原始划分中的同组交叉，隔离后当前测试集该类仅剩 4 张。因此，类别召回尤其不稳定，不能宣称完整物理叶片隔离或真实农田泛化。

划分保持原始 train/test 边界；验证集和公共池各取约 10% 的训练组，余下训练组用 Dirichlet alpha=0.3 分配给 12 个客户端。每组只属于一个客户端。测试农场分区是合成基准；公共池用于校准与蒸馏，测试集不参与优化和模型分配。

## 3. 系统架构与实现

客户端运行 32/64/128 通道的三块 CNN，输入 96×96，无 BatchNorm。主流程每轮邀请 6 个客户端、等权聚合成功上传者。客户端传输权重为 1，不发送精确数据集大小作为聚合权重。

Flower ClientApp 与 secaggplus_mod 执行真实密钥交换、秘密份额、掩码向量和解掩码；传输层在单进程内进行 Protobuf 序列化。模型版本、轮次、最佳检查点、设备状态和隐私账本持久化。单写入者文件锁防止并发写入同一账本，原子替换防止部分文件写入，运行时异常有有限次数恢复。

本实现没有跨主机部署的认证传输与进程安全隔离。模拟器可以访问所有客户端内存；保护主张必须限定为所执行机制与协议，而不能扩大到恶意本机操作者。

## 4. 隐私与容错证据

Poisson 抽样、逐样本裁剪、Gaussian 噪声与 RDP 会计均基于 Opacus。裁剪范数 1，delta=1e-5，epsilon 上限可设 4 或 8。物理微批次只减少内存，不增加逻辑更新次数；空采样批次仍进行加噪更新。混合采样率／噪声情况下的缓存会计与官方 accountant 数值一致。

隐私账本在每次逻辑步骤之前持久预留消耗。故障注入测试覆盖训练后中断、手动恢复、自动重试和三客户端掉线导致聚合中止，验证全局模型可回退而预算不回退。缺失账本拒绝继续。保护单位是图片，不是整片叶片或整个农场；公开随机种子仅适用于实验复现，生产部署需要安全随机性与跨运行预算组合。

SecAgg+ 在更新收集阶段可容忍六个客户端中的两个掉线，三个掉线时中止；unmask 阶段恢复已收到的贡献。所固定 Flower 版本的早期密钥交换掉线边界通过提前安全中止处理，无明文回退。真实协议向量测试验证平均值在固定点编码误差范围内正确。

## 5. 硬件感知与调度

主机为 RTX 5060 Laptop、约 8 GB 显存与约 32 GB 系统内存。训练 profiling 对 CPU/GPU 的 batch 8/16/32 分别测量时间、进程 RSS 和 GPU 显存。完整 CPU DP 训练运行时超过 512 MB，所以摄像头档不具备训练资格；手机与网关参与真实优化，摄像头仍可使用约 70 MB 进程内存的 ONNX 推理。

调度器先过滤 RAM、电池、可用性、截止时间与隐私预算，再保留两席给等待最久者，其余按预计完成时间选择。对照包括均匀、仅速度和带等待保护三种策略。客户端可用性、掉线与抖动在选择前生成，固定 seed 对应相同外生轨迹。

模拟时间使用 CPU 主机成本、设备倍率、消息字节、带宽与 RTT 估算；实际单机运行时间另列。当前事件近似未独立建模所有密码运算在异构设备上的耗时，能耗也只是 compute/radio 代理。部分开发运行共享主机资源，实际 wall time 不应用于声称公平的速度提升；主要调度比较必须使用同一冻结 profile 的模拟时间，并保留上述误差边界。

## 6. 三种子预实验

已完成 21 个短预算运行。统一配置来自 configs/pilot.json：最多 8 轮、每次 10 本地步、SGD 学习率 0.03、batch 16、五轮验证耐心；划分不随训练种子改变。epsilon cap=8，主掉线率为 10%。下表不是完整训练预算的最终课程结论。

| 方法 | 完成种子数 | 测试 Macro-F1 均值 ± 样本标准差 |
|---|---:|---:|
| centralized | 3 | 0.0298 ± 0.0016 |
| full | 3 | 0.0260 ± 0.0026 |
| local | 3 | 0.3898 ± 0.0245 |
| speed_private | 3 | 0.0421 ± 0.0297 |
| uniform_dp | 3 | 0.0277 ± 0.0083 |
| uniform_nonprivate | 3 | 0.0255 ± 0.0044 |
| uniform_private | 3 | 0.0277 ± 0.0083 |

local-only 的表中指标由各农场互不重叠的测试预测合并混淆矩阵后计算，以覆盖同一总体测试集；原始每农场平均 F1 另存于运行结果，不能与全局 F1 混淆。

短预算下多种方法输出近乎单一类别，无隐私基线也存在这一现象，说明不能把质量下降简单归因于隐私机制。独立集中式优化诊断使用 Adam、学习率 0.001、最少 20 轮及 10 轮验证耐心，最佳验证 Macro-F1 为 0.3909，测试 Macro-F1 为 0.3545。该结果来自单一种子、不同训练配置，不能归入下方 SGD 三种子对照。

正式质量阈值目前尚未冻结，time-to-target 明确记为未配置。因此没有声称实现 15% 的达标时间改善。需要先根据验证集建立有效训练配置，再对全部方法统一冻结数据与预算、完成正式三种子比较及单因素压力测试。

## 7. 压缩、推理与动态行为

以下为三轮冒烟教师的真实导出与独立 ONNX Runtime CPU 进程测量，batch=1、4 线程、10 次预热和 30 次计时；延迟不含图片预处理。

| 模型 | 大小 KiB | 压缩倍数 | CPU p50/p95 ms | 验证 Macro-F1 |
|---|---:|---:|---:|---:|
| teacher_fp32 | 371.61 | 1.00 | 1.202/1.422 | 0.0268 |
| teacher_int8 | 106.82 | 3.48 | 0.654/0.893 | 0.0268 |
| student_int8 | 36.39 | 10.21 | 0.566/0.803 | 0.0455 |

该教师本身质量很低，所以即使相对大小／F1 损失条件满足，也不能据此声称获得实用的疾病分类器。正式压缩结论应重新使用质量合格的同一教师检查点。INT8 仅在实际算子支持、基准测量和校准验证后纳入注册表。

动态模型分配按验证 F1、内存、预测 p95 延迟及相对教师质量门槛选择。资源轨迹演示覆盖正常、延迟收紧、内存压力和恢复；固定分配产生预算违例时，动态分配会切换或明确暂停。所有模型下发字节与联邦训练通信分别统计，推理模型变小不代表训练更新变小。

## 8. 测试与复现

自动化测试覆盖分组隔离、重复隔离、真实密码协议的各阶段掉线、DP 账本与预算、物理微批次、版本检查、单写入者锁、失败重试及动态分配。最新执行结果保存于 artifacts/test_results.txt。Streamlit AppTest 已检查真实运行记录的页面渲染，实际 predict 命令调用了导出的 ONNX 模型。

使用 README 的环境、数据、profiling、train、export、suite 与 report 命令可复现流程。依赖闭包锁定在 requirements-lock.txt；每次运行保存配置、主机、数据哈希、模型版本、逐轮记录和预算。suite 可生成主比较和压力测试配置；生成配置本身不表示实验已执行。

## 9. 局限与下一步

1. 优先解决训练质量：验证更长训练、优化器和统一早停策略，之后冻结正式比较；不能用测试集反复选择配置。
2. 完整物理叶片映射缺失及 Target Spot 小测试集是数据局限。需要额外映射或经明确说明的重新分组方案，才能提高无泄漏结论强度。
3. 512 MB 训练不可行本身是硬件发现，不能删除运行时内存来制造可行性。应探索更轻运行时或把该档明确设为推理节点，并分析训练覆盖损失。
4. 当前为单机、公开数据模拟与非安全随机种子实验；真实农场部署需要认证、隔离、安全随机性和跨运行会计。
5. 完整 42 项主比较／压力配置已提供，但并非全部执行。公开未达标、未执行和未配置结果是报告的一部分。
