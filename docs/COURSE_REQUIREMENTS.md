## 验收映射

| 目标 | 实现位置／证据 | 判断边界 |
|---|---|---|
| 完整联邦系统与复杂实现 | CNN、本地优化、等权聚合、SecAgg+、checkpoint、版本检查、错误中止 | 单机真实计算与协议模拟，不是跨机构生产部署 |
| 隐私保护 | Opacus、持久 RDP 账本、安全聚合掉线测试、日志允许字段 | 图像级 DP、模拟随机性、无串通假设 |
| 硬件感知 | CPU/GPU 性能测量、RAM 约束、网络与电池代理、推理注册表 | 512 MB 节点可能仅推理；虚拟设备数据为预测 |
| 压缩与优化 | FP32、静态 INT8、窄学生蒸馏、独立 ONNX 基准 | 验证真实算子支持，不保证量化加速 |
| 自适应与监控 | 公平性保留名额、预算退出、资源变化后的模型分配、Streamlit | 监控来自真实日志，设备约束来自仿真配置 |
| 深入分析 | 基线、三种子配置、单因素压力测试、消融、mean/std 与失败记录 | 完成配置生成不等于完成全部正式实验 |
| 专业文档 | README、隐私模型、来源、配置、结果与代码测试 | 最终 8—10 页报告必须以实际正式实验结果为依据 |

## 与原提案相比必须保留的修正

1. 官方叶片映射并不完整。十类审计模式与严格分组子集要分开解释，不能继续声称所有记录均有物理叶片隔离。
2. 主机完整 PyTorch CPU DP 训练进程超过 512 MB；对不满足 RAM 的虚拟节点应拒绝训练而不是忽略运行时内存。
3. 安全聚合的早期掉线与更新上传后的掉线恢复能力不同，报告中必须分阶段描述。
4. 3× 压缩、至多 3 个百分点 F1 损失与 15% 模拟时间收益仍是待检验目标，不是验收前已达成结果。
